Mission

{% if get_locale() == "ja" or get_locale() == "ja_JP" %} PubCaseFinder の目指す未来 {% elif get_locale() == "ko" or get_locale() == "ko_KR" %} PubCaseFinder 가 지향하는 미래 {% else %} PubCaseFinder's Vision {% endif %}
{% if get_locale() == "ja" or get_locale() == "ja_JP" %}

希少・遺伝性疾患に関する「世界中のすべての症例」を検索可能にすることが、私たちの長期的なミッションです。
このミッションを達成するために、臨床遺伝専門医をはじめとする医療関係者が必要な情報に迅速かつ的確にアクセスできるシステムを構築しています。

{% elif get_locale() == "ko" or get_locale() == "ko_KR" %}

희귀·유전성 질환에 관한 ‘전 세계의 모든 사례’를 검색할 수 있게 하는 것이 저희의 장기적 미션입니다. 이 미션을 달성하기 위해 임상 유전 전문의를 비롯한 의료 관계자들이 필요한 정보를 신속하고 정확하게 이용할 수 있는 시스템을 구축하고 있습니다

{% else %}

Our long-term mission is to make “every case worldwide” of rare and genetic diseases searchable. To achieve this mission, we are building a system that enables clinical geneticists and other healthcare professionals to access the information they need quickly and accurately.

{% endif %}
